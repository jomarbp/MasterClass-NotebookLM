# Masterclass: Creacion de Contenidos Educativos con IA y NotebookLM

## Descripcion del Curso

Curso practico de **4 horas** donde los participantes aprenderan a utilizar herramientas de Inteligencia Artificial (ChatGPT, Gemini, Copilot) y **Google NotebookLM** para crear contenidos educativos de alta calidad de forma eficiente.

**Caso practico guia:** Inteligencia Artificial - conceptos, aplicaciones y tendencias.

---

## Requisitos Previos

- Cuenta de Google (para acceder a NotebookLM)
- Cuenta en al menos una herramienta de IA: ChatGPT, Gemini o Microsoft Copilot
- Materiales propios de su especialidad (PDFs, documentos, presentaciones) - opcional
- Navegador web actualizado (Chrome recomendado)

## Flujo de Trabajo del Curso

```
[Herramientas IA]          [Google NotebookLM]           [Producto Final]
      |                           |                            |
  Generar contenido    ->    Alimentar Notebook    ->    Crear materiales
  con prompts                con fuentes                 educativos
  estructurados              curadas                     listos para usar
      |                           |                            |
  ChatGPT / Gemini         PDFs, textos,               Videos, presentaciones,
  / Copilot                URLs, videos                mapas mentales, fichas
```

## Como usar este repositorio

1. **Sigue el orden de los bloques** - Cada bloque construye sobre el anterior
2. **Personaliza los prompts** - Reemplaza las `[VARIABLES]` con tu especialidad
3. **Practica con tus materiales** - Usa contenido de tu area profesional
4. **Explora los recursos** - Los trucos y tips te ayudaran a sacar mas provecho

---

> **Nota:** Este curso esta disenado para educadores, capacitadores y profesionales que desean integrar IA en su proceso de creacion de contenidos educativos.
