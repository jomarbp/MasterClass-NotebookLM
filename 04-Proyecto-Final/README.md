# Bloque 4: Proyecto Final

**Duracion:** 45 minutos
**Objetivo:** Consolidar los aprendizajes seleccionando, desarrollando y presentando un producto educativo final listo para aplicar.

---

## Dinamica del Proyecto Final

Cada participante seleccionara **un producto final** para desarrollar y presentar al grupo. Este producto debe ser un recurso educativo completo y listo para usar en su practica profesional.

---

## Opciones de Proyecto Final

### Opcion A: Guion de Video Educativo

**Que entregar:**
- Guion completo con timestamps
- Indicaciones visuales para cada segmento
- Notas de produccion
- Duracion del video: 5-10 minutos

**Pasos en NotebookLM:**
1. Selecciona las fuentes mas relevantes para tu tema
2. Usa el chat para generar el guion base:
   ```
   Crea un guion de video educativo de 8 minutos sobre
   "[TU_TEMA_ESPECIFICO]" dirigido a [TU_AUDIENCIA].

   Incluye:
   - Intro con pregunta gancho (30 seg)
   - 3 secciones de contenido con ejemplos (6 min)
   - Resumen visual y cierre (1:30 min)

   Para cada seccion incluye:
   - Texto exacto del presentador (LOCUCION)
   - Descripcion de lo que se ve en pantalla (VISUAL)
   - Graficos o textos superpuestos (GRAFICO)
   ```
3. Refina el guion pidiendo mejoras especificas
4. Genera un Audio Overview como referencia del tono
5. Guarda el guion final como nota

**Criterios de calidad:**
- [ ] Tiene estructura clara (intro, desarrollo, cierre)
- [ ] Incluye indicaciones visuales
- [ ] El lenguaje es apropiado para la audiencia
- [ ] Incluye al menos 2 ejemplos practicos
- [ ] Tiene timestamps definidos

---

### Opcion B: Presentacion Educativa Completa

**Que entregar:**
- Estructura de 12-15 diapositivas
- Contenido de cada slide
- Notas del presentador
- Sugerencias visuales

**Pasos en NotebookLM:**
1. Genera la estructura usando el chat:
   ```
   Disenha una presentacion de 15 diapositivas sobre
   "[TU_TEMA]" para [TU_AUDIENCIA].

   Para cada diapositiva incluye:
   - Titulo
   - 3-5 puntos de contenido
   - Sugerencia de elemento visual
   - Notas del presentador (que decir)
   - Tiempo estimado

   La presentacion debe durar 25 minutos en total.
   ```
2. Pide notas detalladas del presentador para cada slide
3. Genera preguntas interactivas para incluir en la presentacion
4. Usa el Studio > Informes como material de apoyo
5. Exporta y organiza el contenido

**Criterios de calidad:**
- [ ] Tiene portada, agenda, contenido y cierre
- [ ] Maximo 5 puntos por diapositiva
- [ ] Incluye notas del presentador
- [ ] Tiene al menos 2 slides interactivos (preguntas al publico)
- [ ] Sugerencias visuales para cada slide

---

### Opcion C: Mapa Mental / Esquema Conceptual

**Que entregar:**
- Mapa mental completo con al menos 4 niveles de profundidad
- Descripcion de cada nodo
- Relaciones entre conceptos
- Version visual (usando herramienta externa)

**Pasos en NotebookLM:**
1. Genera el mapa mental base:
   ```
   Crea un mapa mental exhaustivo sobre "[TU_TEMA]"
   basandote en las fuentes.

   El mapa debe tener:
   - 1 tema central
   - 5-6 ramas principales
   - 2-3 sub-ramas por cada rama
   - Detalles o ejemplos en el ultimo nivel

   Usa formato jerarquico con simbolos:
   TEMA CENTRAL
   ├── Rama 1
   │   ├── Sub-rama 1.1
   │   │   ├── Detalle/Ejemplo

   Ademas, indica 5 relaciones cruzadas entre conceptos
   de diferentes ramas.
   ```
2. Pide una version ampliada con definiciones en cada nodo
3. Genera una tabla resumen de los conceptos del mapa
4. Exporta a una herramienta visual (Canva, Miro, MindMeister)

**Criterios de calidad:**
- [ ] Tiene al menos 4 niveles de profundidad
- [ ] Incluye definiciones en los nodos
- [ ] Muestra relaciones entre ramas
- [ ] Es visualmente claro y organizado
- [ ] Cubre los temas principales de las fuentes

---

### Opcion D: Hoja de Actividades / Ficha de Aprendizaje

**Que entregar:**
- Ficha de aprendizaje o actividad completa
- Objetivos de aprendizaje
- Actividades variadas (comprension, aplicacion, creacion)
- Criterios de evaluacion

**Pasos en NotebookLM:**
1. Genera la ficha completa:
   ```
   Crea una ficha de aprendizaje profesional sobre
   "[TU_TEMA]" para [TU_AUDIENCIA].

   Incluye:
   - Titulo y datos generales (duracion, nivel, modalidad)
   - 3 objetivos de aprendizaje medibles
   - Conceptos clave con definiciones (tabla)
   - Contenido principal resumido
   - 4 actividades progresivas:
     * Actividad de comprension
     * Actividad de analisis
     * Actividad de aplicacion
     * Actividad de creacion/reflexion
   - 5 preguntas de autoevaluacion con respuestas
   - Rubrica de evaluacion
   - Recursos complementarios
   ```
2. Pide que genere las respuestas de las actividades (para el docente)
3. Genera un set de flashcards complementario
4. Usa Studio > Cuestionario y Tarjetas didacticas como material adicional

**Criterios de calidad:**
- [ ] Objetivos medibles y claros
- [ ] Actividades variadas y progresivas
- [ ] Incluye criterios de evaluacion
- [ ] Contenido preciso basado en las fuentes
- [ ] Listo para entregar a estudiantes

## Flujo de Trabajo para el Proyecto Final

```
1. ELEGIR          2. PLANIFICAR       3. GENERAR
   Selecciona         Define tu           Usa el chat de
   tu opcion          tema, audiencia     NotebookLM para
   (A, B, C o D)      y alcance           crear el contenido

4. REFINAR         5. COMPLEMENTAR     6. PRESENTAR
   Itera y            Usa el Studio       Comparte tu
   mejora el          para agregar        producto con
   contenido          extras (audio,      el grupo
                      cuestionario, tarjetas)
```

---

## Tips para el Proyecto Final

### 1. Enfocate en tu especialidad
Usa un tema real de tu practica docente o profesional.

### 2. Selecciona fuentes clave
No uses todas las fuentes. Selecciona solo las 3-5 mas relevantes para tu proyecto.

### 3. Itera el contenido
No te quedes con la primera respuesta. Pide refinamientos:
```
"Mejora la seccion de ejemplos con casos mas actuales"
"Simplifica el lenguaje para un publico no especializado"
"Agrega una actividad practica despues de cada concepto"
```

### 4. Aprovecha el Studio
Genera recursos complementarios con las opciones automaticas del Studio:
- **Cuestionario** para generar preguntas de repaso y evaluacion
- **Mapa mental** para visualizar la estructura del tema
- **Tarjetas didacticas** como flashcards de repaso rapido
- **Informes** como resumen academico estructurado
- **Audio Overview** como recurso auditivo adicional

### 5. Documenta tu proceso
Guarda como notas las versiones intermedias para poder compararlas.

---

## Presentacion del Proyecto (ultimos 15 minutos)

Cada participante tendra **3-5 minutos** para presentar:

1. **Que producto creaste** y por que elegiste esa opcion
2. **Cual es el tema** y para quien esta dirigido
3. **Muestra el resultado** (compartir pantalla)
4. **Un truco o tip** que descubriste durante el proceso
5. **Como lo vas a usar** en tu practica real

## Caso Practico IA - Ejemplo de Proyecto Final

### Proyecto: Presentacion "IA para Educadores"

**Producto:** Presentacion de 15 diapositivas
**Tema:** Como integrar la IA en la practica docente
**Audiencia:** Profesores de educacion superior

**Diapositivas generadas:**
1. Portada: "IA para Educadores: Guia Practica"
2. Agenda
3. Que es la IA? (definicion simple + analogia)
4. Tipos de IA relevantes para educacion
5. Herramienta 1: ChatGPT en el aula
6. Herramienta 2: NotebookLM para investigacion
7. Herramienta 3: Generadores de imagenes
8. Caso practico: Crear un curso con IA
9. Caso practico: Evaluar con IA
10. Riesgos y consideraciones eticas
11. Que NO puede hacer la IA
12. Actividad interactiva para el publico
13. Hoja de ruta: primeros pasos
14. Recursos y herramientas recomendadas
15. Preguntas y contacto

**Complementos generados:**
- Audio Overview: "IA y Educacion en 10 minutos"
- Cuestionario: Preguntas de comprension y evaluacion sobre IA
- Mapa mental: Estructura visual de conceptos de IA
- Tarjetas didacticas: Flashcards de terminos clave de IA
